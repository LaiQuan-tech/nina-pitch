# nina-pitch

美強光 AI 數位系統 — **提案簡報**（Apple 風全螢幕 pitch deck，模仿 `LaiQuan-tech/agec-pitch`）。

- 線上：<https://nina-pitch.vercel.app>
- 純靜態站（單一 `index.html`）。
- **push 到 `main` → Vercel 自動部署**（Vercel 專案 `nina-pitch`，framework=static，原生 GitHub 整合）。

## 內容
封面 → 兩種經營成本 → 兩大目標（減少客戶來回溝通／減輕交接與培訓）→ 一套整合系統 → 六大重點功能（AI 客服／AI 收稿／AI 即時報價／AI 客戶記憶／ERP 與自動工單／公司知識後台）→ 功能實機 → 運作流程 → 八週時程 → 報價（未稅 165,000）→ 結尾。
